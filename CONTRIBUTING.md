# Contributing

Thanks for your interest in contributing to `npm-license-scraper`!

## Getting started

1. Fork and clone the repository
2. Install dependencies: `npm install`

## Submitting changes

1. Create a branch off `master`
2. Make your changes
3. Run `npm test` to verify nothing is broken
4. Open a pull request with a clear description of what changed and why

Maintainers cut releases via the `Release` GitHub Actions workflow, which bumps the version, builds, and publishes to npm.

## Reporting bugs

Open an issue at <https://github.com/inthepocket/npm-license-scraper/issues> with steps to reproduce.
